Add a meeting transcript

Choose a .txt transcript. It is checked first; nothing is stored until you press Add.
Adding makes 2 to 5 model calls: it reads this meeting, then re-links this team's decision threads. Other teams are untouched.
Transcript format 
Meeting: ACME7c            (optional; defaults to the file name)
Team: ACME7                (optional if the id is the team name plus one letter)
Meeting number: 3          (optional if the id ends in a letter: a = 1, b = 2, ...)
